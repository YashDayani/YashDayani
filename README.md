<h3>Featured Projects</h3>

| Project | What it is | Stack |
| :-- | :-- | :-- |
| 🎙️ **[Rattle](https://github.com/YashDayani/Rattle)** | Dictation and meeting notes for macOS. Hold a key, speak, and the text lands wherever your cursor is. Transcription runs on-device with whisper.cpp, there's no meeting bot, and it ships with Shortcuts, an MCP server, and signed in-app updates. | Swift · SwiftUI · whisper.cpp |
| 🗜️ **[ArchiveX](https://github.com/YashDayani/ArchiveX)** | A fast, native archive manager for macOS with its **own archive engine**. It opens and creates ZIP, 7z, RAR (3 and later, including a RAR writer), TAR and more, with no third-party code. | Swift · SwiftUI |
| 💬 **[Feedspace](https://feedspace.io)** | A platform for collecting and showcasing testimonials. I work on the Next.js frontend, the embeddable widget, the public API docs, and an MCP server. | Next.js · TypeScript |
| 🏢 **Kalaa System** | An internal operations platform: customers, delivery, finance, and CRM with in-browser calling. It also covers Facebook and Instagram post, Reel, and Story scheduling, and an in-app assistant. I've merged **160+ PRs** here. | TypeScript · Meta Graph API |
